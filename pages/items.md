# Items

In Shobon no Action there are many collectible items.

# Mushroom

## Shobon Action 1 & 2

In the original game 3 types of mushrooms can be found in levels:

The non-poisonous Mushrooms are usually named "Delicious Mushroom", since one of the types will make Shobon say "Delicious!" after picking it up.

There is a second type that will make Shobon say "Not poisonous but...", probably referencing the previous Poisonous Mushrooms trap in the same level.

The third one is different, when eaten it will make syobon big and start breaking all blocks he touches, it also can be eaten by [Jiens and Super Jiens](jien.md)

The last type is the Poisonous Mushroom, which will kill the player when touched.

## Syobon Action 3

In Syobon Action 3 some new mushrooms were added, not all of them can be eaten:

The first one appearing is a trap trigger, when the player hits a block containing it a trap will be activated, where a Big Mushroom will fall breaking all blocks below it and killing the player.

The second one is a green mushroom (similar to Super Mario 1UP Mushroom), however eating it does not give any effect.

The last new one is a glowing big mushroom that can be eaten, it will make the player extremely big and break all blocks he touches.

# Fire Flower

Will kill Shobon when touched.

# ? Ball

When picking it up, some unknown thing will happen in the level (usually triggers a trap), it is also required for beating some levels.

# Coin

Can be collected, but it's useless (except for Syobon Action 5, since a level requires you to collect a certain amount of coins to progress).

# Sword

# Shobon Action 1

Found at the end of level 1-4, will break the bridge where Molalla is and trigger a walking animation, however Shobon will be inevitably killed by [Kukkuru](kukkuru.md) since you can't dodge him in the walking animation.

# Shobon Action 2

Found at the end of level 2-4, behaves similar to Shobon Action 1, but instead it will finish the game and trigger credits.

Also note that this change in Syobon Action 2 affects the level 1-4 that is included in this version, making it finish the game instead of killing the player!
